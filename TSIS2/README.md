# TSIS 2 — Paint Application

Расширенный Paint на Pygame.

## Запуск
```bash
pip install pygame
python3 paint.py
```

## Управление

| Клавиша | Инструмент |
|---------|-----------|
| P | Карандаш |
| L | Прямая линия |
| R | Прямоугольник |
| C | Круг |
| Q | Квадрат |
| T | Прямоугольный треугольник |
| Y | Равносторонний треугольник |
| H | Ромб |
| E | Ластик |
| G | Заливка |
| X | Текст |
| F | Fill / Outline |
| 1/2/3 | Размер кисти (2/5/10px) |
| Ctrl+S | Сохранить PNG |
| N | Очистить холст |
| ESC | Выход |
